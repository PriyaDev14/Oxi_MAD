PulseOx - installable app (PWA)
1. Upload this whole folder to any HTTPS host (Netlify Drop, GitHub Pages, Cloudflare Pages).
2. Open the URL on your phone.
   Android Chrome: menu > Install app.  iPhone Safari: Share > Add to Home Screen.
3. Opens full-screen from the home screen and works offline.
Local test: python3 -m http.server 8000 (localhost counts as secure on the same device).
